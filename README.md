# EventFinder

A simple web application that helps users discover local events based on categories and preferences. Designed to provide an intuitive and visually appealing way to explore events happening nearby.

---

## 🚀 Features

- Browse events by category (Music, Sports, Tech, etc.)
- Clean and responsive UI
- Event filtering functionality
- Simple navigation between pages
- Dark mode support (if implemented)
- Lightweight and fast (pure HTML, CSS, JS)

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling and layout  
- **JavaScript** – Interactivity

## ▶️ How It Works
The homepage displays available events
Users can navigate to the Categories page to filter events
JavaScript dynamically shows/hides events based on selection
UI is styled using a centralized CSS file for consistency

## 🧩 Key Components
| Component       | Description                |
| --------------- | -------------------------- |
| Navbar          | Navigation between pages   |
| Event Cards     | Displays event details     |
| Category Filter | Filters events dynamically |

## 🚧 Limitations

No real authentication system
